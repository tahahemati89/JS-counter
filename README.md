# 🔢 JS Counter

A simple and modern Counter application built with **Vanilla JavaScript** and **Tailwind CSS**.

This project was built as part of my JavaScript project practice, with a focus on strengthening DOM manipulation, event handling, and interactive UI development.

---

## ✨ Features

- ➕ Increase the counter
- ➖ Decrease the counter
- 🔄 Reset the counter
- 🎨 Modern and responsive UI
- 🖱️ Interactive button controls
- ⚡ Instant updates without page reload

---

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Git & GitHub

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tahahemati89/JS-counter.git
```

### 2. Open the project

```bash
cd JS-counter
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run Tailwind CSS

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

### 5. Run the project

Open `index.html` in your browser or use **Live Server** in VS Code.
